    Codes for failures raised by the messaging UI package.

    One code per distinct action a consumer can take in response. Several failures may share a code; MessagingUiErrors holds the specific conditions behind each.

    Type Declaration

    • ReadonlyALREADY_INITIALIZED: "OSE_MSG_UI_ALREADY_INITIALIZED"

      Messaging UI has already been initialized

    • ReadonlyALREADY_LOADED: "OSE_MSG_UI_ALREADY_LOADED"

      Messaging UI has already loaded

    • ReadonlyATTACHMENT_DOWNLOAD_FAILED: "OSE_MSG_UI_ATTACHMENT_DOWNLOAD_FAILED"

      An attachment could not be downloaded.

    • ReadonlyCONFIG_NOT_SET: "OSE_MSG_UI_CONFIG_NOT_SET"

      The operation needs configuration that has not been supplied yet.

    • ReadonlyINVALID_CONFIG: "OSE_MSG_UI_INVALID_CONFIG"

      A required configuration value was missing or rejected.

    • ReadonlyINVALID_THEME: "OSE_MSG_UI_INVALID_THEME"

      The requested theme could not be applied.

    • ReadonlyLIFECYCLE_BUSY: "OSE_MSG_UI_LIFECYCLE_BUSY"

      A lifecycle operation is in flight; wait for it to settle.

    • ReadonlyNOT_INITIALIZED: "OSE_MSG_UI_NOT_INITIALIZED"

      The operation requires Messaging UI to be initialized first. Either the AvayaInfinityOmniSdkMessagingUi.init() hasn't been called or its returned promise hasn't settled yet.

    • ReadonlyNOT_LOADED: "OSE_MSG_UI_NOT_LOADED"

      The operation requires Messaging UI to have loaded completely. Either the AvayaInfinityOmniSdkMessagingUi.load() hasn't been called or its returned promise hasn't settled yet.

    • ReadonlyNOT_PRIMARY_INSTANCE: "OSE_MSG_UI_NOT_PRIMARY_INSTANCE"

      The operation is only valid on the primary instance.

    • ReadonlySESSION_NOT_CREATED: "OSE_MSG_UI_SESSION_NOT_CREATED"

      The underlying SDK session has not been created.
