    Codes for failures raised by the Messaging module.

    One code per distinct action a consumer can take in response. Several failures may share a same code; the error's detail field distinguishes them.

    Type Declaration

    • ReadonlyATTACHMENT_REJECTED: "OSE_MSG_ATTACHMENT_REJECTED"

      The attachment was refused by the server.

    • ReadonlyATTACHMENT_UPLOAD_FAILED: "OSE_MSG_ATTACHMENT_UPLOAD_FAILED"

      The attachment could not be uploaded.

    • ReadonlyCONVERSATION_NOT_FOUND: "OSE_MSG_CONVERSATION_NOT_FOUND"

      The referenced conversation no longer exists.

    • ReadonlyFETCH_MESSAGES_FAILED: "OSE_MSG_FETCH_MESSAGES_FAILED"

      Conversation messages could not be retrieved.

    • ReadonlyINVALID_MESSAGE_ELEMENT_TYPE: "OSE_MSG_INVALID_MESSAGE_ELEMENT_TYPE"

      A supplied message element was of an unsupported type.

    • ReadonlyINVALID_STATE: "OSE_MSG_INVALID_STATE"

      The operation is not valid for the current state of the conversation or channel.

    • ReadonlyJWT_INVALID: "OSE_MSG_JWT_INVALID"

      The supplied JWT was rejected.

    • ReadonlyMALFORMED_SERVER_EVENT: "OSE_MSG_MALFORMED_SERVER_EVENT"

      An event received from the server could not be interpreted.

    • ReadonlyOPERATION_TIMEOUT: "OSE_MSG_OPERATION_TIMEOUT"

      The operation did not complete within the allowed time.

    • ReadonlySDK_NOT_INITIALIZED: "OSE_MSG_SDK_NOT_INITIALIZED"

      An operation was attempted before the SDK finished initializing.

    • ReadonlySEND_MESSAGE_FAILED: "OSE_MSG_SEND_MESSAGE_FAILED"

      The message could not be sent.

    • ReadonlySERVER_ERROR: "OSE_MSG_SERVER_ERROR"

      The server returned a response the SDK could not act on.

    • ReadonlySERVER_UNREACHABLE: "OSE_MSG_SERVER_UNREACHABLE"

      The server could not be reached.

    • ReadonlySESSION_ENDED: "OSE_MSG_SESSION_ENDED"

      The session is no longer usable and the SDK must be initialized again.

    • ReadonlyTRANSCRIPT_UNAVAILABLE: "OSE_MSG_TRANSCRIPT_UNAVAILABLE"

      The conversation transcript cannot be produced.
