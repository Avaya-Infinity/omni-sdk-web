    Codes for failures raised by the Core module.

    One code per distinct action a consumer can take in response. Several failures may share a same code; the error's detail field distinguishes them.

    Type Declaration

    • ReadonlyCONVERSATION_NOT_ACTIVE: "OSE_CORE_CONVERSATION_NOT_ACTIVE"

      The operation is not valid for the current state of the conversation.

    • ReadonlyCONVERSATIONS_NOT_CLOSABLE: "OSE_CORE_CONVERSATIONS_NOT_CLOSABLE"

      Creating or ending conversations is not permitted for this integration.

    • ReadonlyCREATE_CONVERSATION_FAILED: "OSE_CORE_CREATE_CONVERSATION_FAILED"

      The conversation could not be created.

    • ReadonlyINVALID_ARGUMENT: "OSE_CORE_INVALID_ARGUMENT"

      A supplied argument was rejected.

    • ReadonlyINVALID_JWT: "OSE_CORE_INVALID_JWT"

      The supplied JWT was rejected.

    • ReadonlyMALFORMED_SERVER_RESPONSE: "OSE_CORE_MALFORMED_SERVER_RESPONSE"

      The server returned a response the SDK could not act on.

    • ReadonlyMAX_CONVERSATIONS_REACHED: "OSE_CORE_MAX_CONVERSATIONS_REACHED"

      No further conversations can be created until an existing one ends.

    • ReadonlySDK_BUSY: "OSE_CORE_SDK_BUSY"

      Initialization or shutdown is in flight; wait for it to settle.

    • ReadonlySDK_INIT_FAILED: "OSE_CORE_SDK_INIT_FAILED"

      The SDK could not be initialized.

    • ReadonlySDK_NOT_INITIALIZED: "OSE_CORE_SDK_NOT_INITIALIZED"

      An operation was attempted before the SDK was initialized.

    • ReadonlySESSION_ENDED: "OSE_CORE_SESSION_ENDED"

      The session is no longer usable and the SDK must be initialized again.

    • ReadonlySESSION_INITIALIZED_ALREADY: "OSE_CORE_SESSION_INITIALIZED_ALREADY"

      Initialization was attempted while a session was already active.
